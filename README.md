# Telco Customer Churn Prediction

A machine learning practice project using the **Telco Customer Churn** dataset from Kaggle.

## Objective

Explore customer behavior and build a classification model to predict customer churn.

## Project Workflow

* Data inspection and cleaning
* Exploratory Data Analysis (EDA)
* Feature engineering
* Data preprocessing
* Classification modeling
* Cross-validation
* Hyperparameter tuning
* Model evaluation
* Model interpretation
* Business recommendations

## Dataset

[Telco Customer Churn — Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost
* Jupyter Notebook
